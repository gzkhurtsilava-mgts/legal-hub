Icon-only square button for toolbars, close actions, and compact controls.

```jsx
<IconButton icon="SettingsSize24StyleOutline" variant="ghost" ariaLabel="Настройки" />
<IconButton icon="CrossSize24StyleOutline" variant="secondary" />
```

Variants `primary`/`secondary`/`ghost`; sizes match Button (`xs`–`l`). Always pass `ariaLabel`.
