Floating option list / context menu (Granat Droplist). Supports icons, dividers and destructive items.

```jsx
<Menu items={[
  { label:'Открыть', icon:'DocumentSize24StyleOutline', onClick:open },
  { label:'Дублировать', icon:'CopySize24StyleOutline' },
  { divider:true },
  { label:'Удалить', icon:'DeleteSize24StyleOutline', tone:'negative' },
]} />
```
