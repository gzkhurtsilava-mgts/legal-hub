Status badge with soft tonal background — for states like «Активно», «На проверке», «Отклонено». Color + label only (no status dot).

```jsx
<Badge tone="positive">Активно</Badge>
<Badge tone="warning">На проверке</Badge>
<Badge tone="negative">Отклонено</Badge>
```

Tones: neutral, positive, warning, negative, brand.
