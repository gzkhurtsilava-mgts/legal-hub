## Format

Each plan contains:
- **Context** — why we're building this, current state
- **Agreed decisions** — all key choices recorded so they don't get re-litigated
- **Architecture** — data model, API surface, component structure
- **Milestones** — ordered, time-estimated chunks of work
- **Verification** — how to confirm each milestone works end-to-end
- **Out of scope** — explicit list of what we're NOT doing in MVP
