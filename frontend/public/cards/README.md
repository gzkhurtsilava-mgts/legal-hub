# 3D-иллюстрации карточек главной

Положить сюда PNG на прозрачном фоне, ~512×512, имя = `id` приложения из `lib/apps.ts`:

- `knowledge.png` — База знаний
- `poa.png` — Доверенности
- `disputes.png` — Статус спора
- `news.png` — Правовые новости
- `documents.png` — Конструктор документов

После добавления файла пропиши путь в `lib/apps.ts` в поле `image`, например:

```ts
{ id: "poa", title: "Доверенности", image: "/cards/poa.png", ... }
```

Если `image` не задан — карточка показывает цветную иконку (текущий фолбэк).

## Стиль (референс — 3D-иконки MTS Design System)

Матовое полупрозрачное 3D-стекло, глянцевые блики, плавный градиент, «надутая»
скруглённая геометрия, объект парит с мягкой тенью, лёгкое зерно на поверхности.
Палитра адаптирована под бренд МГТС: доминирует синий `#008ae0`, прохладные
перивинкл/циан блики, немного лаванды на светах. Без красного. Один объект по центру,
изометрия ~35°, прозрачный фон — чтобы читалось и на светлой, и на тёмной теме.
